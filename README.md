A one-image front page summing up the world news of Thursday 19 November 2026: the Trump–Xi–Putin trilateral summit in Shenzhen as the lead story, plus the ICJ Rohingya ruling, Anthropic's record $81bn IPO, the GTA VI launch, the COP31 deadlock in Antalya, burning tankers east of Hormuz, turmoil in Bangladesh and a record $190.4m Van Gogh sale. The picture is drawn with Pillow by `draw.py` (stories and sources in `SOURCES.md`), packed into `main.ts` by `pack.mjs`, and written out verbatim when the program runs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
